# 🎯 Guess My Number!

A simple number guessing game developed with JavaScript.

This is part of **The Complete JavaScript Course 2025: From Zero to Expert!**. It's about DOM manipulation and basic game development.

---

## 📌 Project Description

'Guess My Number!' is a simple browser game that:

- Computer picks a random number between 1 and 20.
- User tries to guess that number.
- Score goes down with each wrong guess.
- Gives feedback:
  - Too High
  - Too Low
  - Corret Number!

You may restart the game and try again.

## 🎮 How Does It Work?

1. A random number is generated using `Math.random()`.
2. User is prompted to make a guess.
3. JavaScript code checks if it is correct or not.
4. Score is updated depending on whether it is correct or not.
5. Game ends when:
  - User guesses the number
  - Score becomes 0
